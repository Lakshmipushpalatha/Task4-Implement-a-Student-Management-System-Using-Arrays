Student Management System Using Arrays in Java

📌 Project Overview

The Student Management System is a simple Java application that manages student records using arrays. It allows users to add, search, update, and display student details through a menu-driven program.

This project was developed as part of my Java Programming Internship at Veda Technology (Day 4/45).

🎯 Objectives

- Learn how to use arrays in Java.
- Understand methods and loops.
- Implement CRUD-style operations.
- Practice conditional statements and switch cases.
- Improve problem-solving and programming skills.

✨ Features

Add Student-

Allows the user to enter a student's ID, name, and marks. It prevents duplicate student IDs.

Search Student-

Searches for a student using their ID and displays their details if the student is found.

Update Student-

Allows the user to update the name and marks of an existing student.

Display Students-

Displays the details of all students stored in the arrays.

Exit
🛠️ Technologies Used

- Programming Language: Java
- Concepts: Arrays, Methods, Loops, If-Else, Switch Case, Scanner
- Compiler: Online Java Compiler or any Java IDE

💻 How to Run the Program

1. Copy the Java source code.
2. Save the file as "Main.java".
3. Open an online Java compiler or a Java IDE.
4. Paste the code into the editor.
5. Compile and run the program.
6. Select an option from the menu and enter the required details.
